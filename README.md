# VergeStore

VergeStore is a modern e-commerce web application built using React, TypeScript, Vite, and TailwindCSS. The project features a sleek UI, smooth animations, authentication flow, sales portal, and cart management system with responsive design.

---

# Features

## Core Features

- Modern Hero Section UI
- Responsive Design
- TailwindCSS Styling
- Smooth Animations using Framer Motion
- React Router Navigation
- Login Authentication Page
- Protected Routes
- Sales Portal UI
- Shopping Cart Functionality
- Add to Cart Feature
- Remove Items from Cart
- Automatic Quantity Updates
- Total Price Calculation
- LocalStorage-based Authentication
